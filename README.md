# Portfolio — 熊谷 駿介

個人のポートフォリオサイト。

## 内容

- `index.html` — トップページ
- `life.html` — サブページ
- `style.css` / `script.js` — スタイル・スクリプト

## 技術スタック

- HTML / CSS / JavaScript（フレームワークなし）
- Netlify（デプロイ、`netlify.toml` / `netlify/` に設定あり）

## デプロイ

Netlifyに接続済み。`main` ブランチへのプッシュで自動デプロイされる想定（`.github` / `netlify.toml` を参照）。

## ローカル確認

`index.html` をブラウザで直接開くか、簡易サーバーで配信する。
